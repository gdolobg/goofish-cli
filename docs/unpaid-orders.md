# 创建待付款订单

`order_preview(item_id)` 读取订单页，不提交。返回规格 `sku_id`、地址
`address_id`（仅展示区域）、当前规格、数量和金额。规格使用接口返回的原生 SKU ID；地址标识为页面地址文本的哈希，不得自行构造。

`order_create_unpaid(item_id, sku_id, address_id, quantity,
max_total_price, request_id)` 根据明确选择下单。金额单位为人民币元。

Agent 应先预览，补齐用户未指定的规格、数量、地址和金额上限。用户已明确授权
所有选项时无需重复确认；涨价超过上限、选项失效或结果不确定时停止。
不调用付款工具，不引导将支付 URL 作为下单成功证据。

创建前启用浏览器上下文支付拦截，创建后提取订单号，再进入订单详情核实
“等待买家付款”。浏览器上下文结束后拦截一并移除。地址/规格控件目前采用
闲鱼网页 CSS 类名前缀，页面结构变更时应明确失败，不猜测选择。

`request_id` 必须在重试中保持不变。同账号同 ID 的请求只处理一次：参数不同
报错，已有结果则直接返回。提交前将待核实记录原子持久化至
`~/.goofish-cli/unpaid-orders.json`；即使进程崩溃也不会自动重提。

状态：

- `unpaid`：已取得订单号，页面确认等待买家付款。
- `created_unverified`：已创建并保存订单号，页面状态尚未核实；打开返回链接核实。
- `needs_review`：调用中断或仍在进行；先检查“我买到的”，禁止换 request_id 自动重提。

记录不包含地址正文、Cookie 或支付链接。不得删除待核实记录来重试提交。
该工具产生真实待付款订单，不是模拟交易。
